Thanks for your interest in contributing to Prakruthi.

Guidelines:

- Fork the repository and create a feature branch.
- Open a pull request describing your changes.
- Keep changes small and focused.
- Ensure the CI workflow passes before requesting review.

Local development:
- Use Docker Compose for a reproducible local environment (`docker compose up --build`).
- Respect existing code style and naming conventions.

Reporting issues:
- Create an issue with steps to reproduce, expected behavior, and logs if available.
